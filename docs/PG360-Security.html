How we protect your data

Security, in plain terms

Every safeguard below is in place today. No system is ever "unhackable" — so we build in depth: multiple independent layers, so a single failure never exposes your data.

🇮🇳

Your data stays in India

All records, ID documents and photos are stored and processed in the Mumbai region (AWS ap-south-1). Your data never leaves the country.

🔒

Encrypted everywhere

Encrypted in transit (HTTPS/TLS on every request) and at rest (AES-256). Data is unreadable if storage media is ever accessed directly.

🧱

Strict per-PG isolation

Database-level Row-Level Security means one PG owner physically cannot read another PG's data. Residents can see only their own bill — never anyone else's.

🪪

Private ID documents

Aadhaar / ID images and signatures are stored privately, never on public links. They open only through secure, short-lived (expiring) links — a leaked URL stops working within minutes.

👤

Access control & audit trail

You decide exactly what each staff member can view, edit or delete. Every action (who added/edited/deleted what) is recorded in an activity log.

🔑

Secure logins

Passwords are hashed with bank-grade algorithms and never stored in readable form — not even we can see them. Minimum 8 characters; two-factor authentication supported.

Infrastructure & privacy

Built on trusted foundations

☁️

Enterprise-grade hosting

Runs on Supabase (Postgres) — SOC 2 Type II certified — over Amazon Web Services, plus Vercel's global edge network with built-in protection against common denial-of-service (DDoS) attacks.

🛡️

No SQL injection / common web attacks

The app never builds database queries from raw text — all data access is fully parameterized, closing off SQL-injection. Security headers (HSTS, anti-clickjacking, MIME-sniffing protection) are enforced on every page.

🧾

You own your data

Your records belong to you. You can export or request deletion at any time. We never sell your data or share it with third parties for marketing.

💾

Backups & recovery

Hosted on managed, replicated infrastructure with automated backups on production plans, so your data is protected against loss.

A note on honesty: security is layered and ongoing. We protect your data with the measures above and keep hardening continuously (firewall/WAF, rate-limiting and regular reviews). If you ever have a specific security requirement, we're happy to discuss it directly.
